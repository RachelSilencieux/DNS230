## 1_MakeCode

- Mon projet est basé d'une lampe aidant les personnes insomniaques à dormir plus facilement. Il y a 3 réglages dans cette lampe comme :

1) RÉGLAGE 1 - Mode détente : Une animation de respiration lumineuse assez visible : la luminosité augmente puis diminue lentement.

2) RÉGLAGE 2 - Mode relaxation profonde : Une lumière plus faible, avec une animation encore plus lente et apaisante.

3) RÉGLAGE 3 - Mode endormissante : Lumière rouge foncé, très faible et très lente. C'est le réglage le plus discret avant l'extinction.


## 2_MakeCode

- Mon projet consiste à aider une personne nouvelle dans le monde de l'arrosage, à mettre les bonnes quantités d'eau dans une plante. 

À l'aide du Circuit Playground, le clic du bouton simule l'arrosage.

Quand la lumière reste verte, cela veut dire que la quantité d'eau est bonne.

Quand la lumière reste bleue, cela veut dire que la plante est innondée.

Quand la lumière reste rouge, cela veut dire que la plante manque d'eau.


## 3_Arduino

- Mon projet consiste à mettre une luminosité automatique, afin de ne pas régler la lumière manuellement.

Par exemple, dans une chambre, si l'éclairage est intense, la luminosité est éteinte.

Si l'éclairage devient sombre, la luminosité est faible.

S'il n'y a plus d'éclairage, la luminosité est intense.
